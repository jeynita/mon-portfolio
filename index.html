SénSanté

Assistant de pré-diagnostic médical pour le Sénégal : à partir des symptômes saisis, un modèle de Machine Learning prédit la maladie la plus probable parmi le paludisme, la grippe et la typhoïde. Le modèle est exposé par une API REST FastAPI, documentée automatiquement (Swagger), et utilisée par une interface web.

Projet académique réalisé pour le cours « Intégration de Modèles IA » à l'ESP. Il ne remplace pas un avis médical.
